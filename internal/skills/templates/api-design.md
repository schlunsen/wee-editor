category: architecture
argument-hint: "[endpoint-or-feature]"
---
Design the API for $ARGUMENTS:

1. Understand the feature requirements and data model
2. Define endpoint routes, methods, and URL structure
3. Specify request/response schemas with types
4. Handle authentication, authorization, and validation
5. Consider error responses and status codes
6. Document rate limiting and pagination if applicable
7. Provide example requests and responses
