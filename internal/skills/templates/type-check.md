name: type-check
description: Add or improve type annotations in code
category: quality
argument-hint: "[file-path]"
---
Improve type safety in $0:

1. Read the file and identify untyped or loosely typed code
2. Add proper type annotations to function parameters and return types
3. Replace `any` types with specific interfaces or types
4. Define missing interfaces and type aliases
5. Ensure consistency with the project's type conventions
6. Verify the code still compiles after changes
