Control Center for Claude Code

Wee

Run, monitor & control AI agents — live sessions, real-time analytics, multi-provider, in a single 15MB binary.

The problem

Developers run dozens of Claude sessions daily. The terminal gives you no history, no metrics, and no way to run agents side-by-side. You lose context, burn tokens, and have zero visibility into what your agents are doing.

What Wee is

A self-hosted control plane that wraps Claude Code with a live web UI, persistent storage, and multi-provider support — all from one Go binary.

Four pillars

01
Connect
Live agent sessions in the browser via WebSocket.
02
Control
Granular permissions, YOLO mode, provider selection.
03
Monitor
Real-time tokens, costs, and tool executions.
04
Persist
SQLite-backed sessions, handoffs, and analytics.

Highlights

  • Live sessions — stream every tool call (Bash, Read, Write, Edit, MCP) in real time.
  • Multi-provider — Claude, DeepSeek, GLM, Kimi, Z.AI, or any Anthropic-compatible API.
  • Real-time dashboard — token usage, costs, git status, and session metrics.
  • Built for speed — single 15MB Go binary, no Node.js, no Docker required.
  • Voice input — local Parakeet v3 speech-to-text.
  • Optional Docker — single-command deploy when you want it.

Built-in skills

Skills are named, reusable playbooks. Wee ships with a starter set, and you can grow your own library.
