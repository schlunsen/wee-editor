Generate documentation for $0:

1. Read the source code and understand its purpose
2. Identify the public API surface (exports, functions, types)
3. Write clear documentation including:
   - Module/function overview
   - Parameter descriptions and types
   - Return values
   - Usage examples
4. Follow the project's existing documentation style
5. Add inline code comments where logic is complex
